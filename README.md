# Interact2Hack · Brandboard extendido

Sistema visual **Señal Neón** de Interact2Hack: logo, color, tipografía, retícula, fotografía, componentes, movimiento, voz y aplicaciones para la web y la app móvil de la edición 2027.

**Ver en línea:** https://aparrauio.github.io/i2h-brand-board/

## Compartir

- Botón **Compartir** en el índice: copia el enlace o lo envía por WhatsApp, LinkedIn o correo (en el celular abre el menú de compartir del teléfono).
- Cada sección tiene su propio enlace, por ejemplo `…/i2h-brand-board/#color`. El ícono de enlace junto al título lo copia, y la barra de direcciones se actualiza mientras se lee.
- Las etiquetas Open Graph y `og-image.jpg` generan la tarjeta de vista previa al pegar el enlace.

## Estructura

```
index.html        Página (HTML, CSS y JS)
assets/fonts/     Big Shoulders Display y Sora (woff2, SIL OFL)
assets/img/       Logos, íconos y fotos
og-image.jpg      Imagen de vista previa al compartir
```
